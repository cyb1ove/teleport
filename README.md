# Teleport

Прототип розширення для Chrome (Manifest V3). Воно бере посилання на Telegram-канал з адресного рядка, читає повідомлення каналу через MTProto від імені вашого акаунта ([GramJS](https://github.com/gram-js/gramjs)) і виводить їх у консоль.

## Збірка

```sh
npm install
npm run build   # або npm run dev — перезбирає при змінах
```

## Встановлення

1. Відкрийте `chrome://extensions` і ввімкніть «Режим розробника».
2. Натисніть «Завантажити розпаковане» та виберіть папку `dist/`.

## Використання

1. Отримайте `api_id` та `api_hash` на https://my.telegram.org → API development tools.
2. Натисніть іконку Teleport і в спливаючому вікні введіть ключі.
3. Увійдіть у Telegram: номер телефону, код, а якщо ввімкнено двофакторну автентифікацію, ще й пароль. Попап можна закривати між кроками, щоб подивитися код: поточний крок зберігається.
4. Відкрийте вкладку з каналом, відкрийте попап і натисніть «Завантажити». Поки йде завантаження, не клікайте поза попапом: він закриється, і завантаження зупиниться.

Повідомлення з'являються у двох консолях:
- консоль попапа (правий клік у попапі → Inspect) містить повні об'єкти `Api.Message`;
- консоль самої вкладки (F12) містить стислий вигляд: id, дату, текст, перегляди й тип медіа.

Підтримувані посилання: `t.me/name`, `t.me/s/name`, `t.me/name/123`, `t.me/c/123/45`, `t.me/+invite`, `web.telegram.org/k/#@name`, `web.telegram.org/a/#-100…`, `tg://resolve?domain=name`.

## Безпека

Рядок сесії дає повний доступ до акаунта. Він зберігається лише в `chrome.storage.local`. Для скрапінгу краще використовувати окремий акаунт. Розширення не вступає в приватні канали автоматично.
